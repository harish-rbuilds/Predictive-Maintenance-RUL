# Dataset setup

This project uses the NASA C-MAPSS Turbofan Engine Degradation Simulation Dataset.

Place the original downloaded archive named `CMAPSSData.zip` in this folder:

```text
data/CMAPSSData.zip
```

The experiment script reads the FD001 and FD002 training, test, and RUL files directly from that archive. The archive is not included in this repository package; obtain it from the official NASA Prognostics Data Repository / C-MAPSS dataset source and follow its terms of use.
